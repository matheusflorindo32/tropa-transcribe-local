# Como contribuir

1. Abra uma issue sem dados sensíveis.
2. Crie branch curta a partir de `main`.
3. Instale `python -m pip install -e ".[dev]"`.
4. Implemente com testes e documentação.
5. Execute Ruff, mypy, pytest e pip-audit.
6. Abra pull request preenchendo o checklist.

Commits sugeridos: `feat:`, `fix:`, `test:`, `docs:`, `ci:`, `chore:`.
Não envie modelos, binários, mídia, transcrições, segredos, dados pessoais ou
arte sem licença comprovada. Mudanças de dependência exigem fonte oficial,
licença e justificativa.
