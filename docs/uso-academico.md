# Uso acadêmico

Adequado para rascunhos de aulas, entrevistas autorizadas e material de
pesquisa. Antes: aprovação ética quando aplicável, termo adequado, finalidade,
acesso e retenção. Sugestão: modelo `small`, idioma explícito, TXT+SRT e pasta
criptografada institucional.

Revise nomes, citações, números e termos; mantenha áudio como evidência primária
conforme protocolo, nunca trate transcrição automática como fonte infalível.
Anonimize antes de compartilhar e exclua conforme plano de dados.
