# Modelos Whisper

Comece com `base`; use `tiny` para diagnóstico, `small` para qualidade superior
e `medium/large` somente com memória e tempo adequados. Para português, escolha
modelos multilíngues, sem sufixo `.en`.

Quantização reduz disco/memória e pode alterar velocidade e qualidade. O
catálogo inclui variantes Q5 oferecidas pelo ecossistema, mas cada arquivo deve
ser confirmado no repositório oficial antes do download.

Desempenho varia com CPU, GPU, RAM, duração, ruído e build. Tamanhos do README
são aproximados. Modelos ficam fora do Git e podem ser apagados da pasta de
dados local quando não forem necessários.
